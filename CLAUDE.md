# Repo notes for Claude

This repository holds several separate projects that different sessions work on:

- `site/southbound/` — Southbound, the open-world game. **Before working on it, read
  `site/southbound/CLAUDE.md`** (rules, workflow, testing) and `site/southbound/FEATURES.md`
  (the feature tracker and backlog). Keep both up to date; they are the memory that survives
  context resets.
- `dragons-kingdom/` — a separate project worked on by another session. Don't edit it from a
  Southbound session, and vice versa.
