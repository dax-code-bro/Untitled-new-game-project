# EMP Shark — Allied Anti-Drone Weapon System

> **Canonical tech entry.** Nothing here to be lost or summarized away.
> Introduced in Mission 6 ("Hellfire") as the counter to the H2.1 bomber swarm.

## What it is
A **special unmanned weapon platform** — the team's answer to mass drone swarms.

## Specs
| Spec | Value |
| --- | --- |
| Type | Small **helicopter** (weaponized, unmanned) |
| Length | **11 ft** |
| Height | **5 ft** |
| Crew | **NONE** — piloted by absolutely no one (fully unmanned airframe) |
| Control | **Remote-controlled** |
| Payload | **Several thousand EMP bomblets** |
| Delivery | Opens a **rear latch** and releases the bomblets all at once — a
  **"shotgun blast"** spread |
| Effect radius | **~45 miles** |
| Effect | **Instantly disables/"deletes" everything powered by an electrical
  engine** within the radius |

## Tactical Role
- The hard counter to the **H2.1 bomber swarm**: a single EMP Shark blast can
  knock **thousands of electrically-powered drones out of the sky at once.**
- Remote operation means it can be flown into the kill box with **no pilot at
  risk.**

## Design Considerations / Flags
- **⚠ Indiscriminate blast (huge collateral footprint).** A 45-mile EMP radius
  that kills *anything* electrically powered would also fry **friendly aircraft,
  the team's own helicopters/planes, vehicles, power grids, and civilian
  infrastructure** caught inside it. This is a meaningful tradeoff — using it is
  not "free." Could be a deliberate dramatic cost (black out a city / risk
  dropping your own birds to stop the swarm), fitting the "Hellfire" theme of
  terrible choices. **Confirm intent:** does the blast discriminate at all, or is
  the collateral part of the tension?
- **⚠ Lore consistency w/ drone power.** The 1948 **H1.0** drones run on a
  **thermal reactor core** ("no battery required") — which would be EMP-resistant.
  The **H2.1 bombers** are evidently **electrically powered** (since EMP is the
  chosen counter). Suggested canon: the newer H2.1 bombers traded the thermal
  core for an **electrical engine** — making them faster/cheaper to mass-produce
  (ties to "Industry") but **vulnerable to EMP.** *(Confirm if you like this
  reconciliation.)*
