# Models

Drop your print files here — `.stl`, `.3mf`, or `.gcode`.

## A naming idea (optional)

Keeping names consistent makes files easy to find later:

```
name_material_nozzle_notes.ext
```

For example:

```
phone-stand_PLA_0.4_v2.stl
benchy_PETG_0.4.gcode
```

## Organizing as it grows

Once you have a lot of files, subfolders help — for example one per project
or per room. Do it whenever it starts to feel cluttered, not before.
