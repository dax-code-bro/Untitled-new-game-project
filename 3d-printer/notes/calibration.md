# Calibration & setup notes

A short checklist for getting good prints. Fill in the numbers that work for
your machine as you find them.

## First-print checklist

- [ ] Bed leveled / mesh set
- [ ] First layer looks even and stuck down (not too high, not squished)
- [ ] Temps set for the material (see `../profiles/`)
- [ ] Filament dry and feeding smoothly

## Dial-it-in prints (in a good order)

1. **First-layer / bed level test** — a single flat layer across the bed
2. **Temperature tower** — find the best nozzle temp for a filament
3. **Retraction test** — reduce stringing
4. **Benchy** — the classic all-round test print
