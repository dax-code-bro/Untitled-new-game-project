# First prints — in order

The K2 arrives fully assembled and auto-levels itself, so you can be printing
quickly. Do these in order and you'll learn the machine as you go.

## 1. The included test print

Print whatever came on the USB drive / built into the touchscreen first, in
**PLA**. Don't change any settings. The point is to confirm the machine works
out of the box before you start changing things.

**Watch the first layer go down.** It should look like flat, slightly shiny
lines pressed lightly together — no gaps, no ridges.

## 2. Benchy

The classic all-round test boat. It stresses overhangs, bridging, curves, and
stringing all at once. Print in PLA.

What it tells you:

| What you see | What it means |
| --- | --- |
| Wispy hairs between the chimney and hull | Stringing → tune retraction, dry filament |
| Droopy overhangs on the bow | Cooling → more fan, or slow down |
| Rough, bulging surface | Over-extrusion → flow rate slightly high |
| Gaps between lines | Under-extrusion → flow low, or partial clog |

## 3. A temperature tower

Prints the same shape at descending temps so you can see which is best for a
specific filament. Worth doing once per new brand/type of filament — brands
vary more than you'd expect.

## 4. Something you actually want

Don't get stuck in calibration-print purgatory. Once Benchy looks decent,
print something real. You'll learn more from a part that has to fit or work
than from another test cube.

## 5. First multicolor print

Once single-color is solid, load the CFS and try a two-color print. See
[CFS multicolor](cfs-multicolor.md) — start with **two colors of the same
brand of PLA** so only one variable is new.

## Good starter projects

- Bag/cable clips — fast, useful, and instantly tells you if dimensions are right
- A phone or controller stand
- Drawer organizers / bin dividers — sized to your actual drawers
- Wall hooks
- Print-in-place hinges or a fidget — impressive and tests tolerances

## Where to find models

Printables, Thingiverse, MakerWorld, and Thangs all have huge free libraries.
Save the ones you like into [`../models/`](../models/) so you don't lose them.
